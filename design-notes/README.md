# Design Notes

This folder is reserved for concise design rationale and iteration notes.

Primary redesign decisions include:

- Preserve the recognizable dark D4Builds visual language
- Use red as the dominant action and emphasis color
- Improve spacing and scanability for long mobile build pages
- Keep equipment information inside consistent cards
- Make skill rotation understandable as a sequence
- Reduce advertisement dominance without removing realistic ad placement
- Keep Paragon and skill-tree visuals readable at mobile width
- Replace unfinished placeholder content with realistic build notes
- Maintain consistent section-heading capitalization and alignment

Future notes can document additional prototype revisions, usability feedback, or portfolio-specific presentation decisions.
